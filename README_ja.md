# Formalized Quantum Computing
[English](README.md)

Lean 4 を用いて、量子計算の基本的な結果を形式化するライブラリです。

現在、このプロジェクトでは基本的な量子状態と量子ゲートを中心に、
Lean による量子計算の形式化を試みています。

## 開発状況

このプロジェクトは現在開発中であり、作者が Lean による量子計算の形式化を
学習する一環として作成しています。

このライブラリはまだ成熟したものではなく、定義や API は今後変更される可能性があります。
この点に留意してご利用ください。

## 内容

現在、このライブラリには以下の内容が含まれています。

- 基本的な量子状態ベクトル
- Pauli `X` ゲートと `Z` ゲート
- Hadamard ゲート
- CNOT ゲート
- `H² = I` や `CNOT² = I` などの量子ゲートに関する基本的な恒等式
- Bell 状態に関する計算
- 量子ゲートはユニタリ行列であらわされ、量子ゲートを作用させても状態ベクトルのノルムは保存される

## 必要環境

このプロジェクトでは Lean 4 と Mathlib を使用しています。

Lean のツールチェーンは `lean-toolchain` で指定され、
Mathlib などの依存パッケージのバージョンは `lake-manifest.json` に記録されています。

## ビルド

プロジェクトのルートディレクトリで、以下を実行してください。

```bash
lake build
```
