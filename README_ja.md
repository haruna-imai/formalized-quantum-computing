# Formalized Quantum Computing

[English](README.md)

Lean 4 を用いて、量子計算の基礎的な概念や結果を形式化する実験的なライブラリです。

量子状態、ユニタリゲート、基本的な量子回路に関する再利用可能な定義と定理の整備を進めています。

## 開発状況

このライブラリは現在開発中です。量子計算全般を網羅するフレームワークではなく、量子計算の形式化に向けた小規模ながら体系的な基盤を提供しています。

現時点では対象範囲が限定されており、開発の進展に伴って定義や API が変更される可能性があります。

## 内容

現在、このライブラリには以下の内容が含まれています。

- `n` 量子ビット系の状態ベクトル、正規化された状態、基本的な1量子ビット状態
- 状態ベクトルのテンソル積、外積、行列の状態への作用
- 計算基底状態の内積に関する性質と、テンソル積の基本的な性質
- ユニタリ行列で表現された量子ゲート（Pauli `X`、`Z`、Hadamard、CNOTゲートを含む）
- 量子ゲートのテンソル積と、テンソル積で表された状態への作用
- `X² = I`、`Z² = I`、`H² = I`、`CNOT² = I` などのゲートの恒等式
- ユニタリ量子ゲートによる内積とノルムの保存
- HadamardゲートとCNOTゲートを用いたBell状態生成の証明

## 必要環境

このプロジェクトでは Lean 4 と Mathlib を使用しています。

Lean のツールチェーンは `lean-toolchain` で指定され、Mathlib を含む依存パッケージのバージョンは `lake-manifest.json` に記録されています。

## ビルド

プロジェクトのルートディレクトリで、以下を実行してください。

```bash
lake build
```
